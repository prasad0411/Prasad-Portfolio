Amdocs Corporation Dec 2023 — May 2025

Enterprise Telecom Platform

Building scalable microservices for Japan's largest cable television provider

Overview

JCOM is Japan's largest cable television operator, serving over 10 million subscribers across the country. I was part of the core engineering team responsible for developing and maintaining the backend microservices that power their subscriber management, billing, and service provisioning systems.

The Challenge

The existing system faced several critical issues that impacted both developer productivity and end-user experience:

  • Database queries were taking 3-5 seconds for common operations, causing timeout issues
  • Test coverage was below 40%, leading to frequent production bugs
  • New team members took 3+ months to become productive due to complex codebase
  • Tightly coupled services caused cascading failures during peak traffic

My Contributions

As a Software Engineering Associate, I took ownership of several key initiatives:

  • Database Optimization: Analyzed slow queries using Oracle's execution plans and implemented composite indexes that reduced query times by 60%. Introduced query caching for frequently accessed data.
  • Microservices Development: Designed and implemented 8 production microservices using Spring Boot, following domain-driven design principles to ensure loose coupling and high cohesion.
  • Testing Infrastructure: Established testing standards using JUnit 5 and Mockito, increasing code coverage from 40% to 80%. Implemented integration tests that caught 30% more bugs before production.
  • Team Mentorship: Created comprehensive onboarding documentation and conducted weekly training sessions on API security, JWT authentication, and microservices best practices.

Results

60% Query Performance Improvement
80% Test Coverage Achieved
30% Reduction in Production Bugs
40% Faster Engineer Onboarding

Published Research — IEEE 2023

Thyroid Disease Classification

Explainable AI for clinical decision support in medical diagnostics

Overview

Thyroid disorders affect over 200 million people globally, yet early diagnosis remains challenging due to subtle symptom patterns. This research developed a machine learning system that assists clinicians in diagnosing thyroid conditions with high accuracy while providing transparent explanations for each prediction.

The Challenge

Medical AI systems face unique challenges that go beyond accuracy metrics:

  • Clinicians are hesitant to trust "black box" models for critical diagnoses
  • Class imbalance in medical datasets leads to poor minority class detection
  • Feature selection must align with clinical understanding
  • Model predictions need to be interpretable for regulatory compliance

My Contributions

  • Data Engineering: Processed and cleaned dataset of 7,200 patient records across 3 thyroid conditions. Implemented SMOTE for handling class imbalance and feature engineering for clinical relevance.
  • Model Development: Evaluated multiple algorithms (Random Forest, SVM, Neural Networks) before selecting XGBoost for its balance of accuracy and interpretability. Fine-tuned hyperparameters using cross-validation.
  • Explainability: Integrated SHAP (SHapley Additive exPlanations) to provide feature importance at both global and individual prediction levels, enabling clinicians to understand why the model made specific recommendations.
  • Publication: Co-authored IEEE paper documenting methodology, results, and clinical implications. Presented findings at conference.

Results

97.6% Classification Accuracy
7,200 Patient Records Analyzed
3 Disease Classes Classified
IEEE Published Research

Cloud Infrastructure Automation

Modernizing deployment pipelines and infrastructure monitoring

  • Monitoring System: Built comprehensive monitoring using Bash scripts and cron jobs with automated alerting via email and Slack integration.
  • Documentation: Created runbooks for common operational tasks, enabling team members to resolve issues independently.

Results

93% Uptime Achieved
25% Less Unplanned Downtime
4hrs Weekly Time Saved
