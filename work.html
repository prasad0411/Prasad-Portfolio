Amdocs Corporation

Oracle Database Optimization for Telecom CRM

Situation

JCOM's CRM platform served 10M+ subscribers but critical subscriber lookups were taking 12+ seconds as data volumes grew.

Task

Optimize performance across 20+ high-traffic queries without disrupting live production systems serving 50K+ daily transactions.

Action

Analyzed execution plans via Oracle AWR, restructured PL/SQL procedures, added composite indexes, and implemented query result caching.

Result

Reduced average query execution time from 12s to 4.8s — 60% improvement — with 99.7% uptime maintained throughout.

Microservices Containerization & AWS Deployment

Situation

Deployment cycles took 45+ minutes with manual config, creating bottlenecks during sprints and risk of configuration drift.

Task

Containerize 3 production Java/Spring Boot microservices and establish a repeatable deployment pipeline on AWS.

Action
