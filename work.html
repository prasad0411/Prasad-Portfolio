Amdocs Corporation

Oracle Database Optimization for Telecom CRM

Situation

JCOM's CRM platform served 10M+ subscribers but suffered from degraded query performance as data volumes grew, with critical subscriber lookups taking 12+ seconds.

Task

Optimize database performance across 20+ high-traffic queries without disrupting live production systems serving 50K+ daily transactions.

Action

Analyzed execution plans using Oracle AWR reports, restructured PL/SQL stored procedures, added composite indexes on frequently joined columns, and implemented query result caching for repeated subscriber lookups.

Result

Reduced average query execution time from 12s to 4.8s — a 60% improvement — while maintaining 99.7% uptime throughout the optimization process.

60% Faster queries
10M+ Subscribers served
99.7% Uptime maintained

Amdocs Corporation

Microservices Containerization & Deployment

Situation

Deployment cycles for CRM microservices took 45+ minutes with manual configuration steps, creating bottlenecks during release sprints and increasing risk of configuration drift.

Task

Containerize 3 production Java/Spring Boot microservices and establish a repeatable deployment pipeline on AWS.

Action

Created optimized multi-stage Dockerfiles reducing image sizes, configured Docker Compose for local development parity, and set up automated deployments to AWS EC2 with health checks and rollback capabilities.

Result

Reduced deployment time from 45 minutes to 8 minutes per release — an 82% improvement — while eliminating configuration drift across environments.

82% Faster deploys
3 Services containerized
8 min Deploy time

Thyroid Disease Classification with XGBoost & SHAP

Situation

Thyroid disease diagnosis relies on complex hormone level interpretation, with existing ML models achieving moderate accuracy but lacking interpretability for clinical adoption.

Task

Develop a high-accuracy, interpretable classification system that clinicians could trust and understand for thyroid disease diagnosis.

Action

Built an XGBoost classification pipeline with SHAP (SHapley Additive exPlanations) for model interpretability. Processed 7,200 patient records with feature engineering, cross-validation, and hyperparameter optimization.

Result

Achieved 97.6% classification accuracy with full SHAP-based explainability. Published in Springer conference proceedings.

97.6% Accuracy
7,200 Patient records

Personal Project

Decentralized Crowdfunding Platform

Situation

Traditional crowdfunding platforms charge high fees (5-10%) and lack transparency in fund management, creating trust issues between creators and backers.

Task

Build a decentralized alternative on Ethereum that provides transparent, trustless fund management with lower costs.

Action

Developed Solidity smart contracts implementing the withdrawal pattern for security, built a React frontend with Web3.js integration, and deployed on Ethereum testnet with Hardhat for testing and deployment automation.

Result

Fully functional dApp supporting campaign creation, ETH contributions, milestone-based fund release, and automated refunds — all enforced by smart contract logic with zero intermediary fees.

0% Platform fees
100% On-chain transparency
