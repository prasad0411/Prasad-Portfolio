## 📋 Project Objective

Interactive personal portfolio showcasing software engineering experience, technical skills, and projects through a modern web interface with creative visualization components.

---

## ✨ Features

- **Interactive Skills Network Graph** - Canvas-based physics simulation with 18 skill nodes
- **Animated Stats Counter** - Impact metrics that count up on scroll
- **Terminal Command Interface** - Interactive CLI in footer for navigation
- **Scroll Reveal Animations** - Content fades in as you scroll
- **Responsive Design** - Mobile-first approach with CSS Grid and Flexbox
- **ES6 Modules** - Modern JavaScript architecture
- **W3C Compliant** - Valid HTML5 and accessible markup
- **Dark Theme** - Professional color scheme optimized for developers

---

## 🛠️ Technologies Used

- HTML5, CSS3, JavaScript (ES6+)
- Canvas API, Intersection Observer API
- CSS Grid, Flexbox
- ES6 Modules
- Netlify

## 🚀 Build Instructions

### Prerequisites

- Node.js (v16+)
- Modern web browser

### Local Development

```bash
git clone https://github.com/prasad0411/prasad-portfolio.git
cd prasad-portfolio

npm install

npm run format

npm run lint

python3 -m http.server 8000
```

Open http://localhost:8000

## 🎨 Creative Components

### 1. Interactive Skills Network

- 18 animated skill nodes with physics simulation
- Hover shows proficiency levels (1-5 stars)
- Category-based color coding
- Smooth animations with reduced bounce

### 2. Animated Stats Counter

- Numbers count up on scroll
- Displays key impact metrics
- Intersection Observer for performance

### 3. Terminal Command Interface

- Interactive CLI in footer
- Commands: help, projects, contact, resume, clear
- Keyboard-driven navigation
